# All components

Everything in the NXUS design system, in one place. Click a tile for a live demo, the
import line, and a props table generated from the component's own types.

New here? Read the <a href="/?path=/docs/guides-ui-style-guide--docs">UI Style Guide</a> first —
it carries the Laws that bind every component below.

<CatalogueCount entries={ALL} /> · the code beside each name is the rule that governs it.
Cite it in review as `// per P-CO9`.

Previews are the **real components**, rendered live against the shipped token layer — so a
tile cannot drift from what the component actually looks like. Where a tile reads
*Open story*, the component only exists on interaction (a dialog, a menu, a drawer) and a
small crop of it would show nothing useful.

Use the toolbar to switch light and dark. Both are fully supported, and no component may be
styled for only one (**L-C8**).

## Primitives

The shadcn/Radix layer underneath, restyled to bind NXUS tokens — no primitive here uses a
default shadcn colour.

Two things to know before reaching for one:

**Only 7 of the 46 are actually imported by app code** — `button`, `input`, `select`,
`checkbox`, `tooltip`, `switch`, `sonner`. They carry an **In use** marker below. The other 39
are stock scaffolding from the Figma Make export; nothing in the app imports them. They are
catalogued so you know what already exists, not to suggest they are load-bearing.

**Where a primitive and the style guide disagree, the style guide wins.** The shadcn button
ships `rounded-md` variants; NXUS buttons are `rounded-full` (**L-R1**) in the three shapes of
**P-CO1**. Each story flags this where it applies.

## Coverage

**17 components + 46 primitives**, across 131 stories. Every shared component in NXUS is
documented.

Not documented, deliberately: the role dashboards themselves (`LeadScoutDashboard`,
`VideoManagerDashboard`, …) are pages rather than reusable components. Of the 113 files under
`src/app`, only **44 are reachable** from the router — the rest are unused rather than dead
(**OR-4**), and they stay in the repo but out of this catalogue.
